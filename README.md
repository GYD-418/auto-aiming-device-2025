# 简易自行瞄准装置（2025 年电赛 E 题）

2025 年全国大学生电子设计竞赛 E 题：简易自行瞄准装置，云台 + 底盘双控制器架构。

## 目录结构

```
├── 云台代码/              # 云台控制器（Keil MDK 工程）
├── 底盘控制代码/          # 底盘控制器（Keil MDK 工程）
├── C-20_Upgrade_Package_V3.8/   # 逐飞/厂家升级包
└── 演示视频 ×3
```

## 技术栈

- 双 STM32 控制器（云台板 + 底盘板）
- 云台 PID 稳定跟踪、自动瞄准解算
- 底盘运动控制
- Keil MDK（C 语言）
